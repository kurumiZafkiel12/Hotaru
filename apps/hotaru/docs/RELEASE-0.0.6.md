Windows 更新仪表盘、独立分流配置和网络诊断工具。

### 更新内容

- 仪表盘采用四列模数网格，拆分上传、下载、系统代理与虚拟网卡卡片，减少留白；保留自定义排列，可在编辑中恢复默认布局。
- 新增独立分流配置，支持 Mihomo YAML 与 Shadowrocket `.conf` 规则链接。出站模式可选择订阅规则、配置规则、全局或直连；配置规则沿用所选节点，替换订阅分流。
- Windows 内置 BrowserLeaks DNS 与 WebRTC 检测，使用 Hotaru 界面展示结果，支持随应用切换语言。
- 修复服务体检和 IP 画像的路线变化误报，恢复网络质量自动采样；服务管理开放更多可选目标。
- 节点地球支持切换详细地图、缩放及查看逐 IP 地理位置；统一工具箱入口与 IP 画像摘要。

### 使用提示

- 内置网页检测需要 Microsoft Edge WebView2 运行时及可访问 BrowserLeaks 的网络。结果只覆盖本次 WebView 测量，不代表其他浏览器或应用均无泄漏。
- `.conf` 仅导入兼容的分流规则，不导入 DNS、重写或脚本。不支持的规则会明确报错并保留原配置。
- 地理位置来自 GeoIP 数据库估计，不是精确门牌位置。IP 原生／广播属性只采用明确判定来源，没有可靠数据时显示未知。
- 本次提供 Windows x64 安装程序与便携包。安装程序未做 Authenticode 签名，可通过 SHA256SUMS 核对下载文件。
