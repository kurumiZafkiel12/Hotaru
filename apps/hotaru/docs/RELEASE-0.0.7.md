Windows 更新代理内核、IP 信息与网络工具。

### 更新内容

- Windows 改用 Hotaru-Core（基于 sing-box 1.14.4），保留系统代理、TUN、节点选择及订阅导入。
- 新增分流预演：输入域名，查看当前规则与计划出口。
- 实时连接显示入口、中转、出口与命中规则；观测不完整时只展示已确认的链路。
- 新增应用流量排行，订阅卡片持久保存自导入以来的累计流量。
- 状态卡与 IP 弹层统一显示 IP 来源、属性与质量，并标明数据来源。
- DNS、WebRTC 与 IP 检测站在应用内打开，保留 STUN 阻断开关；移除节点地球。
- 补齐服务专属图标，改进服务检测、路线校验、资源缓存与自动刷新。

### 升级说明

- 本次发布 Windows x64 安装版和便携版。Android 继续使用既有版本，后续单独更新。
- 升级前导出配置备份并从托盘退出旧版。原文件和偏好会保留；升级后需手动重新导入订阅或配置。
- 导入会检查配置差异。不兼容的协议、规则或资源格式会明确列出，未通过检查的配置不会启用；MRS 规则集暂不支持。
- 网页检测需要 Microsoft Edge WebView2。结果反映当前应用内网页的检测环境，不能代表其他浏览器或所有应用。
- 安装程序未做 Authenticode 签名；下载后可使用 SHA256SUMS 核对文件。
