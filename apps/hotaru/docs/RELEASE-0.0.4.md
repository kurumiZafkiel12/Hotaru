## Hotaru v0.0.4 · 仪表盘与网络体检

更新 Windows 与 Android 的仪表盘和工具箱，提供更清晰的运行状态与网络诊断结果。

### 更新内容

- 仪表盘采用冷黑与石板灰配色，默认聚焦状态/IP、实时速度、出站模式和网络接管。
- 桌面组件拖动与缩放增加虚线预览，松手后提交布局，支持恢复默认布局。
- 测速页采用双弧仪表盘，集中显示延迟、抖动、下载和上传。
- 服务体检提供 57 个服务入口、分类筛选、单项重试与实际规则、策略组和节点链路。
- 工具箱提供 DNS 检查、原生 STUN、IP 画像与 Windows 网络急救。
- Android 更新启动过渡、快捷磁贴和通知图标；安装兼容修订采用固定正式签名，支持覆盖更新。

### 使用提示

- 连通不等于账号或内容解锁；家宽资格、DRM 和音乐版权等结果仍需相应服务验证。原生 STUN 不能替代完整浏览器 WebRTC 检查。
- 升级保留已有布局，可通过「编辑 → 恢复默认 → 完成」切换到默认布局。
- Android 请重新下载本页最新 APK 覆盖安装；早期 `.dev` 调试包请先备份再迁移。若仍出现解析错误，可在 Issues 附系统版本与错误截图反馈。
- Windows 安装程序未做 Authenticode 签名，请核对 SHA256SUMS；Android 证书核验信息见下载区。
