## Hotaru v0.0.5 · 紧凑仪表盘与网络诊断

Windows 与 Android 同步更新，重整仪表盘、主题和工具箱。

### 更新内容

- 桌面卡片支持三档高度与独立宽度，统一网格与紧凑排版；手机采用独立布局。
- 状态卡分别展示 IP 属性、接入类型和网络质量，支持多次采样查看延迟与波动。
- 更新主题预览、启动过渡及组件拖动；主页服务状态专注连通性和延迟。
- 测速增加动态指针、实时曲线与路线信息，修复节点卡片测速的出口绑定。
- 独立服务体检提供 63 个入口、分类筛选、结果统计及实际规则与节点链路。
- 新增多源 IP 画像、节点地球；整合 DNS 回执与原生 WebRTC 检查。
- Android 增加系统网络状态、DNS 信息及网络设置入口；Windows 保留网络急救工具。

### 使用提示

- 检测证据不足时显示未知。连通不代表账号、地区内容或 DRM 解锁；IP 风险信息来自第三方，不能保证任何服务可用。
- DNS 缺少期望解析器基线、WebRTC 未获取有效候选时，不能判定无泄漏。原生 ICE 检查不等于全部浏览器检测。
- 现有布局会保留，可在仪表盘编辑中恢复默认布局。
- Android 延续固定正式签名，可覆盖此前正式版 0.0.5；早期 `.dev` 调试版需备份后迁移。
- Windows 安装程序未做 Authenticode 签名，下载后可对照 SHA256SUMS 核验文件。
