## Hotaru v0.0.5 · 仪表盘改版测试版

Windows 与 Android 同步提供新的界面测试包。本版仍在完善，建议先备份配置。

### 本次改进

- 仪表盘统一列宽、间距和卡片尺寸规则，窗口变化时按统一栅格排列。
- Android 使用独立紧凑尺寸，状态卡根据可用宽度和出口数据调整高度。
- 状态卡保留左侧国旗及国家信息，IP 标签允许换行，运行时长和组织信息不再挤在一条省略行中。
- 缩减网络接管、网速和内存卡片的留白，并修正紧凑布局下的内容溢出。

### 测试范围与注意事项

- 主题设置、拖拽、长 IPv6 显示及网络工具仍在完善，本版不代表完整改版已经完成。
- DNS、WebRTC 和 IP 属性检测仍有准确性限制，请勿仅凭当前诊断结果判断隐私安全、原生 IP 或服务解锁。
- Android 延续正式包名和证书，可覆盖现有正式版；请下载与设备架构一致的 APK。
- Windows 提供 Setup 和 ZIP；安装程序未做 Authenticode 签名，请核对 SHA256SUMS。
