## Hotaru v0.0.5 · 深绿定稿与诊断重做

Windows 与 Android 同步更新：仪表盘按深绿定稿重做，工具箱的测速、流媒体、DNS、IP 画像与节点分布全部重做。

### 更新内容

- 仪表盘回到萤火深绿：统一栅格对齐，卡片分 122 / 160 / 198 三档固定高度，间距与内边距统一为 12；拖动时其他卡片实时让位，松手平滑归位，不再支持逐个缩放组件。
- 状态卡定稿：国旗徽章加国家代码与国名，标签顺序固定为 IP 属性 → 接入类型 → 质量评级（评级只有优 / 良 / 差 / 未知），大 IP、运行状态、运行时间与组织同卡呈现。
- 手机端单独适配：双列紧凑栅格，一屏可见更多卡片，内容完整不裁剪。
- 主页服务状态只测连通：少量常用服务逐行显示延迟，不再混入解锁结论。
- 流媒体解锁测试独立成页：110 个服务按 AI、流媒体、国内、社交、开发者与游戏分类，给出已解锁 / 未解锁 / 地区不支持等明确结论，延迟小字附带，支持单项重试与仅看未解锁。
- 测速页重做：带指针的刻度表盘（0–1G+），延迟 → 下载 → 上传阶段进度、四项结果、实时速率曲线与出口节点 / 路由规则 / 服务器信息同屏呈现。
- DNS 泄漏测试重做：先给结论，再列出真正应答的解析器（IP、主机名、运营商、国家），系统与内核两条路径分别取证。
- IP 画像重做：五家定位源并排对照，风险系数标注来源（proxycheck），原生 / 广播、住宅 / 机房徽章，WebRTC 与 DNS 泄露结论整合进本页；查不到的数据显示未知。
- 新增节点地球：批量定位全部节点出口并打点到可旋转、缩放的 3D 点阵地球上，按地点聚合，点开可见背后的节点；另有平面模式。
- 外观设置回归固定品牌主题：深绿配色不再随任意取色改变。
- 工具页改用与仪表盘一致的卡片语言，并修复标题与首行重叠。

### 使用提示

- 连通不等于解锁：主页服务状态只回答「连得上吗」，解锁结论请看工具箱的流媒体测试。
- 诊断结论只覆盖本次样本与所测路径；来源无数据的项目会显示未知，不会编造。
- Android 请下载本页最新 APK 覆盖安装，签名与 0.0.3 / 0.0.4 相同，可直接升级。
- Windows 安装程序未做 Authenticode 签名，请核对 SHA256SUMS。
