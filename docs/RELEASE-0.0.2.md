## Hotaru v0.0.2 · 萤火桌面

更新仪表盘布局与主题，完善运行状态展示和配置管理体验。

### 更新内容

- 新增紧凑侧栏、出口主卡片和可编辑组件布局。
- 改进深浅色主题与国旗显示，保留已有订阅、规则和自定义组件。
- 修正窗口失活或最小化时的焦点处理。
- 改进诊断日志轮转和后台解析，减少长时间运行时的日志占用。
- 修正卸载时选择删除数据后的目录清理。

### 安装说明

Windows 在托盘完全退出后覆盖安装；便携版解压到新目录。Android 正式包支持同架构覆盖更新。建议提前备份配置，并核对 SHA256SUMS。Windows 安装程序未做 Authenticode 签名。
