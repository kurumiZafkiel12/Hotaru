## Hotaru v0.0.2 · 萤火桌面

### 界面与功能

- 启用「萤火桌面」：窄侧栏、出口主卡片、小组件分区，以及新的深浅色配色、圆角和轻量阴影。
- 保留 IP 质量检测、详情与重新检测、上传下载、配置流量、内网 IP、服务检测、内存、连接和策略组等现有功能。保留已有订阅、规则、覆写和小组件设置。
- 出口地区显示国旗，使用内置字体，无需联网加载国旗；未知地区和检测中的状态仍有回退。

### 修正与优化

- 修正 Windows 失去激活或最小化时仍把键盘焦点设回自身的问题，避免该代码重新激活窗口。此问题可能造成窗口切换时的闪动、阴影变化；仍需用户实机确认是否覆盖所报告的全部现象。
- 诊断日志改为追加写和有界轮转，最多保留两个各 2 MB 的文件；读取尾部与 JSON 解析移到独立 isolate。关闭诊断时不创建日志。
- 修正卸载时用户明确选择「删除用户数据」后的目录；常规覆盖安装保留用户配置。

### 安装与更新

Windows 10/11 x64。先在托盘完全退出 Hotaru，再运行下方 Setup 安装包覆盖安装；便携版请解压到新目录后使用。v0.0.1 可手动覆盖升级，无需删除订阅或配置。更早的 0.5.x 版本因版本号重新编号，请手动下载更新。

安装包未签名，请核对本页 SHA256SUMS。配置和节点凭据无需上传。

### 验证边界

已验证实际 Flutter 界面的桌面/窄窗口、深色/浅色布局，并复测原有小组件、IP 质量详情、编辑及刷新流程。窗口焦点修正经 Windows 安装包构建验证；尚未取得用户机器的闪动复测结果。随机 UI 卡死仍未定位根因；本版不宣称已彻底解决卡死，也不承诺长期覆盖更新零残留或自动删除 Downloads 中的安装包。

基于 FlClash / Mihomo，保留上游许可证与贡献者署名。此版本开始独立维护产品 UI，不表示已经移除所有上游来源代码和依赖。
