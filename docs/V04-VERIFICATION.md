# v0.4 开发与验收

作者：Codex，2026-10-24；基线 61e1d7d（Muse v0.3）。

目标：安装后无需另找内核，导入节点、启动代理、设置系统代理并持续运行，后续覆盖升级保留数据。

本机已通过原有 38 项 Flutter 测试、静态分析零问题、Windows Mihomo 真实双实例本地代理链路（选择、延迟、HTTP、连接链证据、停止后端口关闭）。新增测试及安装验证以最终 CI 结果为准。

本轮修复：IndexedStack 保留节点页面；自动定位内置内核；端口输入校验；跨订阅切换要求停止；切换/测速异常处理；系统代理写入串行保护、旧备份保护、失败回滚、WinINet 设置变更通知；正常退出清理；内核异常退出恢复；启动中 dispose 的进程创建竞态；Windows 单实例/Job Object。

安装：Inno Setup 固定 AppId，当前用户安装，无管理员要求，保留 %APPDATA%/Hotaru。更新为下载新 setup 覆盖安装；不实现后台自更新。CI 运行安装/覆盖升级/卸载测试，并验证旧数据保留。

未完成：TUN、多跳、应用级规则编辑、测速下载、IP 数据源、托盘、开机启动。未用用户的真实订阅/公网节点测试。强制退出会由 Job 回收子进程，但系统代理只能下次启动恢复；Windows Job 绑定失败不应宣称强退回收有保障。用户凭据仍是本地明文存储。本轮未迁移为凭据加密存储。

完整配置的客户端覆写：只保留受控的回环混合端口和带认证的回环控制接口，关闭其他入站/listeners、远程控制端点、外部面板及 TUN；用户规则/策略/DNS 内容仍受 Mihomo 语义检查。不会因为配置声明 allow-lan 就对局域网开放入口。
