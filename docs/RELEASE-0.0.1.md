### 安装

Windows 10/11 x64。先从托盘完全退出 Hotaru，再运行下方 Setup 安装包覆盖安装；也可以解压 Portable 到新文件夹。版本号从 0.5.x 重置为 0.0.1，请手动下载安装；无需删除已有订阅与配置。

### 验证边界

隔离实测已复现统一延迟关闭/开启的测量差异，同一批节点可从约 516/414/311 ms 变为 128/78/75 ms；这是实际 HTTP 探测结果，不是固定倍数缩放。用户已在原安装中添加统一延迟与 TCP 并发覆写并确认恢复正常。该结果不保证所有节点可用，也不证明每次超时都来自同一原因。服务端不可达的节点仍会显示失败或超时。旧版本只在新安装包通过可用性确认后清理。
