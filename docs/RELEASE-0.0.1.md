## Hotaru v0.0.1

基于 Mihomo 的 Windows 与 Android 代理客户端，提供配置管理、节点切换、分流和网络工具。

### 更新内容

- 统一延迟与 TCP 并发的默认覆写，修正设置开启但未实际生效的问题。
- 默认加入 IPv6 和 Geo 低内存模式覆写，保留已有开关值与规则。
- 延迟检测增加错误类别与耗时信息；本地诊断按需开启。
- 简化首次启动流程，完善关于页和社区入口。

### 安装说明

Windows 退出托盘进程后覆盖安装；Android 正式包可在相同架构与签名之间覆盖更新。早期 `.dev` 调试包需先备份配置再迁移。仍在使用 0.5.x 的安装需手动下载更新。Windows 安装程序未做 Authenticode 签名，请核对 SHA256SUMS。
