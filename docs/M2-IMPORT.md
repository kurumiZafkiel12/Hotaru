# M2a：导入预览

本阶段实现输入解析和 Flutter 导入预览入口；不是完整订阅管理。

支持：Mihomo YAML/JSON 中显式 proxies 列表；仅提取节点/保留完整配置字段；SOCKS5、HTTP、HTTPS 和基础 Trojan URI（Trojan 仅支持 sni 查询参数）。未知参数拒绝处理。节点名称重复、端口越界、无效结构和超过 2 MiB 的输入会失败。

订阅下载仅支持 HTTPS，20 秒总超时、10 秒连接超时、2 MiB 上限，不跟随重定向。链接仅用于用户点击后的请求；不进入日志或持久化。未测试真实用户订阅服务，不承诺服务商兼容性。

当前结果保留在预览操作内存中，只显示数量；没有保存、更新、应用、回滚。完整配置字段保留不代表已验证其 Mihomo 语义。远程 provider-only、Base64 订阅、SS、VMess、VLESS、Hysteria2 等导入仍待实现。

后续验收：协议解析样例矩阵 → 配置语义校验 → 加密/系统凭据存储设计 → 原子保存及失败回滚 → 订阅定时更新 → 节点管理界面。

自检覆盖两种导入模式、编码凭据、IPv6、重复节点、未知参数、大小限制、非 HTTPS 拒绝，以及页面成功/失败状态切换。网络超时与响应上限目前只有实现，尚缺受控 HTTPS 集成测试。
