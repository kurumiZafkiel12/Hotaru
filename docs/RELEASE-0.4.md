# Hotaru 0.4.0 Windows 安装预览版

下载安装文件 Hotaru-0.4.0-windows-x64-setup.exe，按提示安装。安装后在“节点”页导入订阅或单节点、选择节点、启动代理，再按需打开系统代理。

- 内置固定校验的 Mihomo v1.19.33，不再需要手填内核路径。
- 切换首页、工具箱和节点页时保持代理运行；首页显示真实内核运行状态。
- 系统代理即时通知、启用失败回滚、正常退出恢复；检测到其他程序已改代理时保留其设置。
- 单实例和 Windows Job Object 回收子进程；异常退出的系统代理可在下次启动用“恢复”按钮处理。
- 安装到当前用户目录，无需管理员权限；同一安装程序覆盖升级，保留订阅和布局。卸载保留用户数据，需清除时可自行删除 %APPDATA%/Hotaru。
- “下载更新”打开 GitHub Releases。当前为手动下载安装包覆盖升级，不是后台自动更新。

安装前关闭其他 Hotaru 实例。不要同时让多个代理客户端管理系统代理。TUN、多跳、下载测速、IP 质量工具尚未接入；订阅及节点凭据保存在当前用户目录的明文 JSON，请妥善保管。

构建流程验证静态分析、测试、真实 Windows 内核本地链路、安装/覆盖升级/卸载；公网服务商节点可用性取决于你的订阅。本版本尚未数字签名。许可、内核源代码和 SHA256 文件随版本提供。
