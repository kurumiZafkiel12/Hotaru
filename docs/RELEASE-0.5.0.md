# Hotaru 0.5.0 · Windows 安装预览

基于 Muse 留下的 FlClash 0.9.2 分支继续完成，产品版本 0.5.0+8，发布标记 v0.5.0+8（保留 Muse 原先无资产的 v0.5.0 标记）。保留 FlClash 的完整自适应界面、首页小组件、订阅管理、节点/策略组、分流、覆写、连接、DNS 记录、日志、备份、托盘、自启与 TUN/Helper 架构。移植 Bettbox 的服务可用性检测引擎；不再用旧版简化表单模拟成熟客户端。

## 下载与升级

下载 Hotaru-0.5.0-windows-x64-setup.exe；便携版需要完整解压 ZIP。Windows 10/11 x64，未签名预览。安装到受保护的 Program Files，首次安装需管理员授权。TUN 使用 Helper 授权路径；不要把便携目录注册为长期高权限服务。

0.4.x 与 0.5 使用不同架构和配置格式。先在旧版托盘退出并恢复系统代理，再安装 0.5；新安装不会删除旧版数据，安装登记独立，旧版可保留回退。不要同时启动两个版本或代理工具。

首次打开 0.5 后，在工具页选择“导出 0.4.x 旧配置”，选旧的 %APPDATA%/Hotaru/profiles.json 和输出目录，再从配置页导入导出的 profile-N.json。完整规则与 Merge 保存在快照中，Script 仅导出不执行；原文件与来源清单一并保留。需要定时更新的订阅请用原 URL 重导，并检查覆写。用户凭据仅保存在本机，导出文件不要公开。

## 本轮新增

- 工具页统一入口：DNS 系统解析、TCP 三次握手检测、HTTP 状态与响应时间、复用已有 IP 质量查询。TCP 不代表下载带宽；HTTP 跟随应用分流规则。
- Bettbox 服务可用性引擎：AI、流媒体和常用网站的地区/可达性测试；按选择运行，无后台自动扫描。可停止，页面退出取消请求。网站风控可能影响结果，结果不代表账户权益。
- 独立 Windows 代理守护：开启前保存 ProxyEnable、ProxyServer、ProxyOverride；UI 崩溃时恢复仍由 Hotaru 占用的代理，正常停用时也恢复快照。保护失败不启用代理，外部后改的代理不覆盖。
- Windows 发布独立于 Android 签名打包；经过 Dart、插件、Go、Rust、Windows Helper 检查后构建安装器，核查安装、覆盖与卸载，并发布校验和及完整对应源码。

## 尚需继续合并与验收

这版已经采用完整 FlClash 基线并移植 Bettbox 检测引擎，不宣称已完成两者所有功能并集。Bettbox 的独立带宽测速、NAT/STUN、路由追踪、iPerf、MRS/AGE 工具、专用脚本 UI 和部分定制体验仍需逐项移植。两者已有重叠功能保留一个入口，完整对照见 FEATURE-MATRIX-0.5.0.md。

本轮面向 Windows x64；Android/Linux/macOS 源码继承不等于本轮安装包已发布或实机验收。TUN 实网、真实用户订阅、托盘/自启和升级交互仍需用户设备验收。首次 Geo/Provider 下载依赖网络。请以 CI 实际结果和发布资产为证，不把未执行的实机检查记为通过。

更新方式：本版沿用 FlClash 的版本检查与 GitHub 下载页入口，后续下载新安装器覆盖安装；未保留旧 0.4 的应用内自动下载安装流程。Windows Helper 沿用上游的高权限 Core 设计，其同账户权限隔离局限仍需后续审查；不要把本版当成完成权限安全审计的产品。
