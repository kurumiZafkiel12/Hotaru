## Hotaru v0.0.4 · 仪表盘与网络体检

本版同时提供 Windows x64 与 Android。沿用 Muse 的 v0.0.3 功能和用户已配置的持久正式签名。

- 首页统一为「仪表盘」。冷黑画布、石板灰卡片、细描边与薄荷强调色；默认聚焦状态/IP、实时速度、出站模式和网络接管，其余组件仍可添加，已有自定义布局保留。
- 桌面网格拖动和缩放改为虚线预览，松手才提交重排；取消清除手势偏移，支持恢复默认比例及保存尺寸。不以此声称已在所有设备测得 60 fps。
- 状态卡采用青蓝波浪控制，速度数字使用等宽字体。测速页采用细双弧、微刻度和四项统计；规则模式不再拿 GLOBAL 的选择冒充实际出口。
- 独立服务体检覆盖 57 个服务入口，参考 Bettbox 的分类、汇总和单项重试；展开可见每个请求的 URL、HTTP 状态、实际规则及策略链。取消会关闭正在执行的请求，路线变动会标记旧结果。
- 区分连通、鉴权、验证拦截、地区阻断及证据不足。Netflix 对照自制与授权标题的播放元数据；Claude 分开检查地区与 Web；Telegram 探测 DC1–DC5 的 MTProto 握手；GitHub raw 对照固定内容哈希。
- 工具箱分为服务体检、极速测速、DNS 泄漏、WebRTC/STUN、IP 画像及 Windows 网络急救。DNS 使用 16 个域名与权威回执，失败时展示回退证据；STUN 比较原生 UDP 反射地址与出口，常见端口阻断可撤销且仅规则模式生效。
- Windows 急救按操作确认后清除当前用户代理/PAC、刷新 DNS，并经原有生命周期恢复 Hotaru TUN，分别报告结果。
- Android 使用系统 SplashScreen 的矢量 Logo 和短淡出、Flutter 首帧淡入上浮；控制中心快捷磁贴及通知图标改为 Hotaru。系统减少动画设置受尊重。

### 结果边界与升级

网页可达不能证明账号、订阅、DRM 或整套曲库/作品授权；通用服务返回 200 会显示「连通，解锁未证实」。Hulu 家宽资格、音乐灰歌版权和账号内实际播放仍需相应账号验证。原生 STUN 不等于全部浏览器 WebRTC 测试，DNS 样本也不能证明所有应用无泄漏。第三方探测协议可能变化，失败会保留证据而非报告全绿。

Android 正式包名为 `dev.hotaru.hotaru`，基础 versionCode 13，继续使用证书 SHA-256 `79:63:BA:5A:37:28:D3:20:E8:2C:DF:B4:3D:58:F7:D3:2B:DF:FD:41:91:13:E2:85:0D:E7:EA:2F:2B:98:7F:AA`。同架构正式签名 0.0.1/0.0.2 可覆盖升级；旧 `.dev` 调试包先备份并迁移一次。Windows 安装包仍未做 Authenticode 签名。建议升级前导出备份。

自动化构建、真实受控链路实验和响应式渲染检查会随交付报告列出；触屏/OEM 磁贴刷新、Windows 原生交互、实际订阅、VPN 长期运行与主观体验仍需要实机确认，不以旧版测试代替本版验收。
