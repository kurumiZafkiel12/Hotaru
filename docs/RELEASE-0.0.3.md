## Hotaru v0.0.3 · 萤火桌面

优化桌面与手机布局，扩展测速来源，并改进节点测速的出口选择。

### 更新内容

- 调整组件尺寸与间距，增加测速和连接表组件。
- 设置成为独立页面，精简工具箱入口。
- 测速页集中展示延迟、抖动、下载和上传，提供九种测速来源。
- 节点卡片测速使用独立通道，经所选节点发送测速流量，保留日常节点选择。
- 改进 Ookla 请求与服务器选择；不支持上传的来源明确标注。
- 优化国旗、侧栏与部分文字标签。

### 使用提示

测速会消耗流量。不同网络下测速来源的可用性存在差异，可切换来源重试。Windows 完全退出托盘进程后覆盖安装；Android 选择相同架构的正式包更新。请核对 SHA256SUMS；Windows 安装程序未做 Authenticode 签名。
