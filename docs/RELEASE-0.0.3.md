## Hotaru v0.0.3 · 萤火桌面

（本版曾于 2026-10-26 首发；以下为按两轮实机反馈重做界面后的再次重新发布，版本号与下载地址不变，安装包内容已更新，请以本页 SHA256SUMS 为准。）

### 界面与功能

- 桌面首页改为固定尺寸的小组件网格：每张卡只有小、中、大三档尺寸之一，拼在同一张格子网里、间距统一、无错落缝隙；编辑时只能拖动换位与增删，不能拉伸改大小，拖动时其他卡片会实时滑动让位，窗口缩放时布局平滑过渡。新增「测速」快捷卡片与「连接表」卡片，可按需添加；手机端沿用原有编辑方式。页面内容在标题栏下方滚动，卡片不会再滑到标题下。
- 工具与设置分开：设置成为独立页面（语言、主题、备份、快捷键、访问控制、高级配置、自定义资源、通用、关于），桌面端点侧栏左下角齿轮在内容区打开设置页（侧栏保留），工具页不再重复列出设置。原「延迟诊断」入口移除。
- 测速页重做：渐变刻度仪表盘配阶段进度与实时速率曲线，一屏看清延迟、抖动、下载、上传；测速源增至九个（Apple、Cloudflare、Speedtest、Fast.com、LibreSpeed、Google、M-Lab、CacheFly、Vultr 东京），每个源都标注详细地址，M-Lab 等动态选服务器的源会显示实际选中的机房；开始前会提示测速将消耗流量。Google、CacheFly、Vultr 为纯下载源，上传如实标注「不支持」。
- 出口国旗放大显示，服务状态里的出口国旗同步放大；侧栏左上角品牌字标缩小。
- 「测速链接」改名为「延迟测试链接」，与它实际用于延迟测试的用途一致。
- 版本号不再带构建后缀，本版为 0.0.3。

### 修正

- 节点卡片的带宽测速改走独立的本地测速通道：测速流量由内核强制经所点节点出站，不再受当前分流规则影响，也不再切换日常所选节点、不再重置全部连接。此前在特定规则下会测到别的出口、且测速约十秒内日常流量被一并带偏的问题，已用受控双出口实验复现并验证修复；测速进行中再点其他节点会提示稍候。
- 修复 Speedtest（Ookla）一直不可用：其服务器接口会拒绝应用默认的请求标识，现改用浏览器标识，并在选定服务器前做一次真实小文件下载校验；上传端点改为接口返回的地址。
- Fast.com 不提供可用的上传通道，界面如实标注「不支持」，不给假数据。

### 安装与更新

Windows 10/11 x64。先在托盘完全退出 Hotaru，再运行下方 Setup 安装包覆盖安装；ZIP 版请解压到新目录后使用。可从 v0.0.1 / v0.0.2 直接覆盖升级，订阅与配置保留。

安装包未签名，请核对本页 SHA256SUMS。配置和节点凭据无需上传。

### 验证边界

- 新增的四个测速源（Google、M-Lab、CacheFly、Vultr）已在开发环境实测跑通完整流程；Speedtest（Ookla）经实机反馈在部分网络下基本不可用（其上传环节亦未能在开发环境完整验证），这类网络请优先用 M-Lab 或 Google 等源。
- 安卓本版仅做静态检查与构建兼容，没有新增安卓功能；安卓的实际开发将在本版 Windows 经确认满意后再开始。
- 节点延迟偏高的问题根因仍未定位，本版不宣称已修复；节点延迟测试与既有的四项延迟相关默认覆写保留不变。
